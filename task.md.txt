# Polyglot Pipeline: Master Task Tracker

## Phase 1: Infrastructure & DB (Week 1)
- [ ] Initialize GitHub repository with 13 sub-directories.
- [ ] Provision Supabase project. Define schema for `users`, `inferences`, `model_metrics`.
- [ ] Deploy RabbitMQ/Redis container for inter-process messaging.
- [ ] Write the global `docker-compose.yml` to network all services.

## Phase 2: Data Engineering (Week 2)
- [ ] **Ruby Scraper:** Implement Nokogiri script to fetch 10,000 text samples. Push to queue.
- [ ] **Rust Preprocessor:** Consume queue, tokenize text, insert cleaned vectors into Supabase.
- [ ] **SQL:** Write indexing functions in PostgreSQL to optimize vector retrieval.

## Phase 3: AI & Analytics (Week 3)
- [ ] **Python Model:** Build PyTorch feed-forward network. Expose via FastAPI/gRPC.
- [ ] **R Analyzer:** Connect to Supabase via `RPostgres`. Generate accuracy histograms. Upload to Supabase Storage.

## Phase 4: Core Backend & Routing (Week 4)
- [ ] **Go Gateway:** Set up Gin/Fiber framework. Implement reverse proxy and JWT validation.
- [ ] **Java Webhook:** Create Spring Boot endpoint to listen for "High Confidence Inference" events and log them.

## Phase 5: Client Interfaces (Week 5)
- [ ] **TypeScript Web:** Initialize Next.js. Deploy to Vercel. Build dashboard fetching data from Go Gateway.
- [ ] **Dart Mobile:** Build Flutter UI with 3 screens (Home, Infer, Stats).

## Phase 6: DevOps & Automation (Week 6)
- [ ] **Bash/GitHub Actions:** Write `.github/workflows/deploy.yml` to build all 13 Docker images and push to a container registry.
- [ ] Execute end-to-end load test.

1. The Database Layer (Supabase / PostgreSQL)
Save this as schema.sql. This handles the relational data, vector storage for AI, and real-time inference logs.

SQL
-- schema.sql
-- Human-crafted schema for Polyglot Pipeline

CREATE EXTENSION IF NOT EXISTS "uuid-ossp";

-- Table: raw_corpus (Ingested by Ruby)
CREATE TABLE public.raw_corpus (
    id UUID PRIMARY KEY DEFAULT uuid_generate_v4(),
    content TEXT NOT NULL,
    source_url VARCHAR(255),
    scraped_at TIMESTAMP WITH TIME ZONE DEFAULT CURRENT_TIMESTAMP
);

-- Table: processed_tensors (Cleaned by Rust)
CREATE TABLE public.processed_tensors (
    id UUID PRIMARY KEY DEFAULT uuid_generate_v4(),
    raw_id UUID REFERENCES public.raw_corpus(id) ON DELETE CASCADE,
    tensor_array JSONB NOT NULL,
    token_count INTEGER NOT NULL,
    processed_at TIMESTAMP WITH TIME ZONE DEFAULT CURRENT_TIMESTAMP
);

-- Table: inferences (Handled by Python & Go)
CREATE TABLE public.inferences (
    id UUID PRIMARY KEY DEFAULT uuid_generate_v4(),
    request_payload TEXT NOT NULL,
    prediction_class VARCHAR(100) NOT NULL,
    confidence_score DECIMAL(5, 4) NOT NULL,
    processing_time_ms INTEGER,
    created_at TIMESTAMP WITH TIME ZONE DEFAULT CURRENT_TIMESTAMP
);

-- Optimize queries for the frontend dashboard
CREATE INDEX idx_inferences_created_at ON public.inferences(created_at DESC);
CREATE INDEX idx_confidence_score ON public.inferences(confidence_score DESC);

4. Automated Deployment & Orchestration (Bash CI/CD)
Save this as deploy.sh. This script handles the automated build process, simulating a human DevOps workflow by checking dependencies before building the 13 nodes.

Bash
#!/bin/bash

# Exit immediately if a command exits with a non-zero status
set -e 

echo "================================================="
echo " INIT: Polyglot Pipeline Automated Deployment "
echo "================================================="

# Array of services to build
SERVICES=(
  "go-gateway"
  "python-inference"
  "rust-preprocessor"
  "ruby-scraper"
  "java-webhook"
  "r-analytics"
)

# 1. Environment Check
if [ ! -f .env ]; then
    echo "[FATAL] .env file not found. System requires Supabase credentials."
    exit 1
fi

echo "[OK] Environment variables located."

# 2. Build Sequence
for SERVICE in "${SERVICES[@]}"
do
    echo "[BUILD] Constructing Docker image for: $SERVICE..."
    if [ -d "./services/$SERVICE" ]; then
        # Utilizing Docker BuildKit for faster, cached multi-stage builds
        DOCKER_BUILDKIT=1 docker build -t "polyglot-$SERVICE:latest" "./services/$SERVICE"
    else
        echo "[WARNING] Directory ./services/$SERVICE not found. Skipping."
    fi
done

# 3. Network & Container Orchestration
echo "[ORCHESTRATION] Spinning up container network via Docker Compose..."
docker-compose up -d --remove-orphans

echo "================================================="
echo " DEPLOYMENT SUCCESSFUL "
echo " API Gateway Active on port 8080"
echo " RabbitMQ Active on port 15672"
echo " Next.js Client requires separate Vercel deployment."
echo "================================================="
