# UI/UX Design System: The Polyglot Pipeline

## Core Philosophy
To avoid the generic "AI-generated SaaS" look (which typically overuses default Tailwind indigo, perfectly rounded corners, and flat vector art), this dashboard must feel grounded, tactile, and highly intentional. 

## 1. Color Palette & Aesthetic
The UI will utilize a minimal design system focused on calm colors to reduce cognitive load when viewing complex data.
*   **Backgrounds & Surfaces:** Deep blacks, warm greys, and muted earthy browns. The application should operate natively in dark mode.
*   **Accents & Data Highlights:** Use a striking golden-orange to draw the eye to primary actions, active states, and critical AI inference results. 
*   **Texture:** Implement a very subtle, CSS-based film grain overlay across the application background. This provides a tactile, "vintage diary" feel that heavily contrasts with sterile, flat modern web apps, giving the interface a premium, human-crafted touch.

## 2. Typography
*   **Headings & Titles:** A refined Serif font to reinforce the classic, diary-like aesthetic.
*   **Data & Code:** A crisp Monospace font (like JetBrains Mono or Fira Code) for all inference logs, API payloads, and telemetry data. 
*   **Body Text:** A highly readable sans-serif with generous line height.

## 3. Layout Rules
*   **Borders over Shadows:** Instead of soft drop-shadows (which look generic), use hard, 1px borders in a lighter grey/brown to separate dashboard panels. 
*   **Micro-interactions:** Keep animations incredibly brief (under 150ms). Focus on subtle opacity changes rather than elements bouncing or sliding across the screen.
